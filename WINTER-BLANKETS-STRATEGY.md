## 3. Competitor intelligence (benchmarks)

### Google (organic)
- Head terms ("horse turnout blanket," "winter horse blanket," "horse turnout sheet," "waterproof," "heavyweight") → Google rewards **CATEGORY pages**. Winners: **Schneiders, Dover, WeatherBeeta, Horseware, SmartPak, Big Dee's, Kensington, Performance Horse Blankets** — *none are DTC western brands → room for us.*
- Spec term "1200d turnout blanket" → **PRODUCT pages**, where we already rank page 1.
- What wins: keyword-first title tags; H1 = head term; **faceted filters** (denier / fill weight / waterproof / size / neck); 150–400 word SEO copy; a **temperature→fill-weight table** (the single most consistent asset); and **hub-and-spoke internal linking** to a "Blanketing 101 / Size Guide" hub.
- Informational queries (size chart, how to measure, weight guide, denier) are owned by **dedicated guide pages** with tables + diagrams + HowTo/FAQ schema.

### Amazon
- Two tiers: budget keyword-front sellers (TGW, Tough-1 Snuggit 300g, Derby Nordic-Tough) own head terms via price + review volume; Brand-Registered premium (Harrison Howard, WeatherBeeta, Kensington, Amigo) win on **A+ content + Brand Store + reviews**.
- Winning title order: `[Brand] + 1200D + Ripstop + Waterproof + Breathable + Turnout Blanket + Winter + Heavyweight + 300g Fill + [Size]`.
- Bars for page 1: **4.3★ min, 100+ reviews credible, 300+ to contend.** Under ~50 reviews you need Sponsored Products to place at all.
- Price bands: sheet $40–70 · midweight $70–130 · heavyweight $85–150 (budget) / $180–300 (premium). Hilason sits value-end with the **400g + belly-wrap** differentiator.

## 4. The plan — channel by channel

### A) Google organic (fully ours — start now)
1. **Rebuild the size-chart page to CONVERT** (highest ROI). We rank #1 and get 0 clicks. Add: measure diagram, inches table (36"→96", 3" increments, "size up if between"), interactive "enter inches → your size," printable, **prominent CTAs + internal links into `/collections/turnout-blankets`**, click-worthy title ("Horse Blanket Size Chart + How to Measure (Free Printable) | Hilason"), and **FAQ + HowTo schema** so we own SERP space instead of feeding a bare snippet.
2. **Add the temperature→fill-weight table** to the turnout-blankets collection page (0–100g / 100–150g / 150–250g / 300g+ keyed to °F) — the one asset every category winner has and ours lacks. Surface faceted filters (denier/fill/size/neck).
3. **Build the hub-and-spoke content cluster** (each links both ways into the collections): Weight Guide · Denier 600D vs 1200D vs 1800D · Turnout Sheet vs Blanket · How to Blanket a Horse in Winter · Best Winter Turnout Blankets (Hilason buyer's guide, to beat Riding Warehouse's "Best of 2026").
4. Pull our **400g + belly-wrap + western-colorway USP** onto the collection page (competitors under-message it).

### B) Amazon (listings + ads — start now)
1. **Reprice/optimize the winter ASINs' listings:** keyword-front titles per the formula; 5 spec-led bullets (lead with 400g heavyweight differentiator); ~250-byte backend search terms (horse rug, paddock rug, pony/mini, 1680d, detachable neck, hi-vis, gusseted, no-rub, windproof…); infographic + lifestyle images; A+ / Brand Story with a size chart + weight-selection table + comparison vs generic 1200D.

Prioritize **heavyweight 300–400g** (Aug–Nov peak). **Get flagship ASIN reviews >100 before scaling spend** (drive via velocity + Amazon review requests).
